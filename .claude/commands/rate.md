---
description: Update a broker's rating, target or estimates, or record the closing price
---

Broker: `npm run ir -- rate <broker> --rating=.. --target=2.85 --eps1=.. --eps2=.. [--date=..]`. Price: `npm run ir -- price 2.28 [--date=..]`. Shares on issue after a raise: `npm run ir -- capital <shares> --date=..`.

Ambiguous names list the candidates and stop: ask which one. Never send anything; drafts stay in `drafts/`.

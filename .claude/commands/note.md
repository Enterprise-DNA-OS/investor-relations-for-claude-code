---
description: Write up a meeting: what was discussed, the mood and the themes. Written once, never rewritten
---

Run `npm run ir -- note <meeting> --notes=".." --sentiment=positive|neutral|negative --themes="margins,guidance"`. Keep themes short and reuse existing ones (`/themes`). Then ask whether anything was promised and record it with `/follow-up`. If anything market sensitive came up that is not already released, say so plainly: Guidance Note 8 expects it to go to ASX straight away.

Ambiguous names list the candidates and stop: ask which one. Never send anything; drafts stay in `drafts/`.

---
description: Record that a result, quarterly or other report was lodged, or the date the AGM notice went out
---

For a report: `npm run ir -- lodge <event> --date=YYYY-MM-DD`. For the AGM notice: `npm run ir -- notice-sent <event> --date=YYYY-MM-DD`.

Ambiguous names list the candidates and stop: ask which one. Never send anything; drafts stay in `drafts/`.

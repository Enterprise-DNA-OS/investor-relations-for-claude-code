Run `npm run ir -- roadshow <code> --json` for one already set up (meetings plus holders and targets in that city not yet booked), or `holders` and `targets` filtered by city for a new one. Check `/blackouts` for the dates. Propose a schedule, then `/itinerary` once it is booked.

Ambiguous names list the candidates and stop: ask which one. Never send anything; drafts stay in `drafts/`.

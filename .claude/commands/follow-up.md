---
description: Record something promised to an investor, with an owner and a due date
---

Run `npm run ir -- follow-up <meeting> <action> --owner=<team code> [--due=YYYY-MM-DD]`. Without a due date it takes the `follow_up_days` setting.

Ambiguous names list the candidates and stop: ask which one. Never send anything; drafts stay in `drafts/`.
